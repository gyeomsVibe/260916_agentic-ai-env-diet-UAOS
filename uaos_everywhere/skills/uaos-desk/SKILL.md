# UAOS 데스크 지휘 및 복붙 제로 실행 계약

사용자의 1단어 단축 명령 또는 날것의 아이디어를 UAOS-RSI 3도구 논스톱 병렬 협업 계약으로 변환하라.

## 실행 프로토콜 3종

### 1. 신규 아이디어 구체화 (`/go <아이디어>`, `총괄 <아이디어>`) — 헌장 제0조 + 적응형 MIA 3단계 라우팅
- **원칙**: 사용자는 1~3줄의 날것 아이디어만 입력한다. 배관/OS 지시 및 복잡도 분류는 OS가 담당한다.
- **Stage 0-R (0토큰 자동 트리아지)**: `intake.py` + `helper_thinking_router.py`가 아이디어 범위·위험 키워드(`권한/삭제/전역/보안/규칙/스키마/아키텍처` 또는 명시적 `MIA모드 발동`)를 0토큰으로 분류해 아래 3개 티어 중 하나를 자동 선택한다.
  - **Tier 1 `MIA-Fast` (4단계, 구조적 -64%)**: `<=2`파일 · 단일 명백 수정 · 외부 스펙/보안 무변경 → `0-R(로컬 실측) → 1(1장 초경량 계약+롤백1줄) → 2(Ollama 실행+테스트) → 3(교차 검증·병합)` (`Low` Thinking, 4대 렌즈 대안비교 생략).
  - **Tier 2 `MIA-Standard` (6단계, 구조적 -45%, 기본값)**: `2~5`파일 · 새 기능/UI · 내부 확장 → `0(공식 URL 1~2건 근거조사) → 1(기획+경량 2안 비교) → 2(세부 계약+Lint) → 3(Ollama/도우미 병렬 실행) → 4(독립 검증·반례) → 5(자율 병합)` (`card_pipeline.py` 4슬롯 `Research/MIA/Execute/Verify` 1:1 호환, `Medium` Thinking).
  - **Tier 3 `MIA-Full` (11단계 정식)**: `>=6`파일 · OS 커널/전역규칙/보안·권한/DB/3도구 프로토콜/`CODEX_EXCLUSIVE_KEYPOINTS` · 사용자 명시 `MIA모드 발동` → `mia-strategic` 11단계 전체 + Vaccine Test (`High` Thinking).
- **자동 상향 승격 안전장치**:
  - Tier 1 실행 중 수정 파일이 3개 이상으로 늘거나 1회 실패·외부 API 확인 필요 시 `MIA-Standard`로 자동 승격한다.
  - Tier 2 실행 중 전역/권한/공유 모듈을 접촉하거나 동일 원인 2회 실패 시 `MIA-Full`로 자동 승격한다.
- **불변 관문 & 실행 절차**:
  1. `python "$HOME/.uaos/uaos.py" coord presence --tool <self> --state ACTIVE`로 출석을 확정하고, `coord quota` 및 `helper-matrix`로 0토큰 리소스 상태를 확인하라.
  2. `Stage 0-R` 분류 등급(`MIA-Fast` / `MIA-Standard` / `MIA-Full`)에 맞춰 기존 전담 카드 창에 병렬 배분하라(누락 또는 60%·12턴·180KB 임계 초과 시에만 신규 창 개설).
  3. 어떤 티어에서도 `author != judge`, 고정 인수 테스트 exit 0, `.work/backup_<date>/`, Safety 사람 전용 7대 목록(삭제/원격푸시/배포/공개게시/유료지출/계정·권한변경/OS설정)은 절대 생략할 수 없으며, Safety 목록 외에는 무승인 논스톱 실행한다.

### 2. 총괄 승격 및 창구 인계 (`/takeover`, `총괄 승격`) — 제어권 단조 펜싱
- **원칙**: 모든 카드 창을 무분별하게 재생성하지 않고, 포인터만 현 `fencing_epoch`로 재바인딩한다.
- **절차**:
  1. 현 대화창을 `Pure-Manager` 사용자 총괄 디렉터로 선언하라.
  2. `fencing_epoch`를 단조 증가시키고 미완료 카드 포인터를 현 창구로 재연결하라.
  3. 컨텍스트 임계(12턴 / 180KB / 60%)를 초과한 창만 선별 회전(Rotate)하고, 정상 가동 중인 창은 그대로 통신하라.
  4. 브리핑 요약 후 3도구 티키타카를 논스톱 지휘하라.

### 3. 한도 리셋 및 동결 해동 (`/resume`, `이어서`, `재개`) — 논스톱 복구
- **원칙**: 2,136자 장문 복붙을 소멸시키고, 0토큰 한도 복구 트리거를 수행한다.
- **절차**:
  1. 한도 리셋 영수증을 확인하고 `STOP` 상태였던 작업 카드 상태를 `READY`로 복구하라.
  2. 동결되었던 자식 카드 세션을 활성화하고 최신 `HEAD` diff를 확인하라.
  3. 미완료된 비작성자 판정 및 남은 태스크를 즉시 재가동하라.

## 안전 및 권한 불변성 (Safety Invariants)
- 어떠한 단축 명령도 Safety 사람 전용 7대 목록(무백업 삭제, 원격 푸시, 배포, 공개 게시, 유료 지출, 계정/권한 변경, OS 설정 변경)을 면제할 수 없다.
- `author != judge` 품질 게이트는 예외 없이 강제된다.

# U282 Codex relay filter: no paid Codex turn for a letter that asks for nothing

User order (2026-10-28 22:5x KST, Claude user desk, MIA strategic): letters already answered or superseded must be
filtered before Codex reads them, implemented in UAOS, merged and made live.

## Frame
- Decision: which letters may become a `codex queue` item (each item = one paid Codex turn, ~140k context).
- Success signal: the 8-relay receipt replayed against the rules; NOTICE/ACK_ONLY/self-addressed letters run no
  `codex queue`; untagged and verdict letters keep today's dispatch; full suite green.
- Non-goals: removing items already in the Codex app queue (no CLI exists: `codex queue --help` has no remove),
  semantic "already answered" detection (needs a model call per letter; ACKed letters are already skipped by the
  existing `ack_file` check in `_deliver_unlocked`).

## Alternatives
1. R1+R2 deterministic gate in `deliver()` (chosen): zero tokens, uses fields the sender already sets.
2. Ollama "is this superseded" classifier per letter: adds a model call and a false-negative risk on verdicts. No-Go.
3. Supersede key (newest letter per actor+card replaces older queued ones): useful for the LIMITED queue, but the
   8 receipts carried no card; parked until a receipt shows two same-card letters queued (operate-first rule).

## Rules
- R1 SELF_ADDRESSED: auto routing skips the sender (codex->codex, claude->claude).
- R2 NO_WAKE: target codex (ACTIVE or queued for LIMITED) and the letter declines a turn (NOTICE class,
  verdict_requested=False, or an unquoted ACK_ONLY marker) -> published to inbox only, reason `QUEUED_NOTICE`.

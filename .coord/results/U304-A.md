## Item 1 — Flagman reads LIVE again

Cause (measured): `write_flagman_independent_presence` stamped `os.getpid()`. Since pulses now come only from
short-lived hook processes (`coord/sentinel.py` → `run_independent_flagman_pulse`), the PID in
`.coord/presence/flagman.json` was dead seconds later, so `flagman_liveness` read `STOPPED / PID_NOT_RUNNING`
beside a fresh pulse. The resident daemon (`.coord/flagman_daemon.json`) was dead and nothing re-spawned it.

Fix:
- `disjoint_mediator.py`: the heartbeat's `pid`/`daemon_pid` name the recorded daemon, never the writer; the writer
  goes to `pulse_pid`/`pulse_source` (`daemon` only when `UAOS_FLAGMAN_DAEMON_PID` equals the writer's PID).
  `daemon_pid` is null when no daemon was ever recorded.
- `ensure_independent_flagman_daemon`: the daemon imports the package the ensurer runs from (the installed
  `~/.uaos/runtime/<ver>` when `uaos` calls it; recorded as `runtime_root`), logs pulse errors to
  `.coord/presence/flagman_daemon.log`, exits when its project disappears or a newer daemon is recorded, and a
  recorded PID reused by a non-Python program no longer counts as alive.
- `capacity_planner.flagman_liveness`: LIVE = fresh pulse AND `daemon_pid` running as Python (`NO_DAEMON` when
  null; old beats with only `pid` keep the U286 rule).
- Re-ensure: `hud_live.serve` ensures the daemon before the first render and every 30 s cycle; `sentinel` hook
  cycle ensures it when the project has `.coord/flagman_daemon.json` (scratch roots never grow a process).

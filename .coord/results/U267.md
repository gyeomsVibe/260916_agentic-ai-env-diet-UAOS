## Counterexample Resolution Matrix (`pr229_4d_independent_review.json` & `pr229_b440579_review.json`)
1. **P1-1 (Incomplete JSONL tail)**: `_scan_agy_brain_transcripts` advances `offset` only up to `last_nl + 1` (the end of the last complete newline-terminated record), so appending the remainder of a partial tail line yields `warm == cold`.
2. **P1-2 (Growing same-path replacement)**: Full consumed prefix hash (`prefix_sha` over `0..prev_offset`) detects file replacement even when the replacement file is larger than `prev_offset`, discarding stale cached events and rescanning from byte `0`.
3. **F1 (Corrupt non-int/negative/boolean watermark offset)**: Explicitly rejects boolean/non-int/negative `offset`, `file_size`, and `mtime` values and falls back to a full rescan from byte `0` without raising `ValueError`.
4. **F2 (Corrupt cached `events` entries)**: Validates that every cached event is a `dict` with numeric `ts` (excluding `bool`) before reusing cached events on both unchanged and append paths.
5. **F3 (Mid-file rewrite after byte 256)**: `prefix_sha` hashes the entire consumed span (`raw[:prev_offset]`), invalidating the cache when any byte after byte 256 is rewritten at the same row length (`[5, 11, 99]`).
6. **F4 (Future timestamp clock skew in `refresh_capacity_zero_token`)**: Enforces `0.0 <= (moment - last_ts) < min_interval_s` so future timestamps (`last_ts > moment`) force an immediate snapshot refresh.
7. **F5 (Debounced `html_out` in `refresh_capacity_zero_token`)**: Always renders `html_out` when requested, even when the snapshot collection itself is debounced.
8. **F6 (Atomic `capacity_head.json` write)**: Persists `capacity_head.json` via `_atomic_write_json(local_head, head_summary, compact=True)` (`tempfile.mkstemp` + `os.fsync` + `os.replace`).

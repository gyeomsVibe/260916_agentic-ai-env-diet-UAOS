## Counterexample Resolution Matrix (`pr229_4d_independent_review.json` & `pr229_b440579_review.json`)

### Regression Locks (Previously Fixed on `main`, Locked by Dedicated Tests in PR #258)
1. **P1-1 (Incomplete JSONL tail — fixed in PR #235 `46572a0` / `9347d88`)**: `_scan_agy_brain_transcripts` advances `offset` only up to `last_nl + 1` (the end of the last complete newline-terminated record), so appending the remainder of a partial tail line yields `warm == cold`.
2. **P1-2 (Growing same-path replacement — fixed in PR #235 `46572a0` / `9347d88`)**: Full consumed prefix hash (`prefix_sha` over `0..prev_offset`) detects file replacement even when the replacement file is larger than `prev_offset`, discarding stale cached events and rescanning from byte `0`.
3. **F3 (Mid-file rewrite after byte 256 — fixed in PR #235 `46572a0` / `9347d88`)**: `prefix_sha` hashes the entire consumed span (`raw[:prev_offset]`), invalidating the cache when any byte after byte 256 is rewritten at the same row length (`[5, 11, 99]`).
4. **F4 (Future timestamp clock skew in `refresh_capacity_zero_token` — fixed in PR #235 `fb3dda8`)**: Enforces `0.0 <= (moment - last_ts) < min_interval_s` so future timestamps (`last_ts > moment`) force an immediate snapshot refresh.

### New Fixes & Hardening Delivered in PR #258
5. **F1 (Corrupt non-int/negative/boolean watermark offset — fixed in PR #258)**: Explicitly rejects boolean (`True`/`False` via `not isinstance(..., bool)`), non-int (`'abc'`), and negative `offset`, `file_size`, and `mtime` values and resets `c_size, c_mtime, c_offset = -1, 0.0, 0` on parse error, falling back to a full rescan from byte `0`.
6. **F2 (Corrupt cached `events` entries including boolean `ts` — fixed in PR #258)**: Rejects boolean `ts` (`not isinstance(ev.get("ts"), bool)`) in addition to non-dict items or non-numeric `ts` values before reusing cached events on both unchanged and append paths. Tested with discriminating fixture `{"ts": True, "raw_total": 77777}` which fails on `origin/main` (`e030527`).
7. **F5 (Debounced `html_out` overwrite in `refresh_capacity_zero_token` — fixed in PR #258)**: Removed the `and not Path(html_out).is_file()` guard so `html_out` is always rendered when requested during a debounced window, overwriting any existing stale HTML file on disk. Tested with discriminating `"STALE_HTML"` fixture which fails on `origin/main` (`e030527`).
8. **F6 (Atomic `capacity_head.json` write — hardened in PR #258)**: Hardened from inline temp-file + `os.replace` to the shared `_atomic_write_json(local_head, head_summary, compact=True)` helper (`tempfile.mkstemp` + `os.fsync` + `os.replace`), adding explicit `fsync` durability while keeping compact `<=320B` formatting.

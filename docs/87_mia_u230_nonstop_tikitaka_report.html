3대 도구 통합 문서 허브 (Unified Document Hub — U233) 핵심 설계

코드 작업은 각 도구의 worktree에서 격리하되, 사용자가 보는 모든 프로젝트 문서와 프로세스 문서는 공유 메인 루트(shared_desk)의 한 곳에서 자동 수집·색인·열람합니다.

현재 문제점 (4곳으로 파편화)
  • Codex: ~/.codex/worktrees/170e/.../.work/U229/에 저장
  • Claude Code: .claude/worktrees/<name>/.work/에 저장
  • Antigravity: ~/.gemini/antigravity/brain/<id>/에 저장
  • CLI 버그: _DESK_COMMANDS에 docs가 빠져 worktree에서 uaos docs new 실행 시 worktree 내부에만 생성됨
해결책: shared_desk 기반 단일 문서 허브
  • 원칙: 코드는 worktree 격리, 문서는 shared_desk(project)/docs/로 단일화
  • 프로젝트 문서: docs/NN_<slug>.{md,html} 연대기 순번 부여
  • 프로세스 문서: docs/process/<CARD>/ 아래에 매뉴얼·감사영수증·완료보고서 자동 미러링
  • 통합 뷰어: docs/00_DOCUMENT_HUB.html + docs/00_DOCUMENT_INDEX.md 동시 자동 갱신

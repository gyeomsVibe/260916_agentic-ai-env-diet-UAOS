\#\# mia 전략스킬 발동 \- /DEEPDIVE /REDTEAM /OPTIMIZE 우후죽순 codex와 antigravity가 따로 작업을 수행하지 말고, 하나의 계획으로 통일 되게 한몸처럼 수행하는 로직을 만들기 위해 아래 사용자 제안을 먼저 읽고, 사용자 제안과 관련 자료를 찾기위해서 깃허브(저장소) 공개자료, 레딧(reddit) 자료 등 웹딥리서치를 활용하여, 심층연구를 통해 최적화 정제한 설계안을 포함하자. (기본전제: 두 도구는 사용자에의해 무승인 권한을 받았다.)

**\-** 각자 도구에서 작업을 할때 "**하나의 대화창에서 작업을 수행할 때 사용자 대화창(지시창)에 말고 각 프로젝트 창에 각 수행작업 마다 한 대화창을 생성해서 계획순서대로 작업을 하자.**

**\- 각 대화창에 짧게 통일된 접두어를 붙여 토큰을 절약한다.**

**\- antigravity가 codex의 업무 조율로 작업을 수행하는 것을 \*\*"codex의 프로젝트 안의 단계별 전용 대화창 취급한다."\*\*** **"**실제 수행은 프로젝트 안의 단계별 전용 대화창에서 계획 순서대로 단일 소유자가 진행한다." 하지만 codex로 프로젝트를 시작하면 antigravity는 codex의 일부분이자 도구이다.

\- codex로 프로젝트를 시작하면, 당연히(반드시) antigravity를 부려 먹어야하므로, codex로 프로젝트를 시작할 때 codex와 antigravity는 자동으로 연결되고, antigravity 2.0이나 IDE를 사용하면 antigravity 단독사용이다, 필요한 경우 antigravity에서 codex를 호출할 수 있다.

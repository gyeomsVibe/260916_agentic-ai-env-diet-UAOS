1. PC 부팅 즉시 & 3대 도구 켜자마자 100% 자동 가동 (Zero-Touch Auto-Boot)

  • PC 부팅 자동 기동: Windows 작업 스케줄러(ONLOGON)에 등록된 coord boot --launch가 PC 부팅 즉시 0토큰 Sentinel 감시 데몬과 로컬 Ollama 서버를 자동 가동합니다.
  • 3대 도구 실행 즉시 자동 편입: Antigravity(PreInvocation), Claude Code(SessionStart), Codex(SessionStart) 전역 훅이 어떤 폴더에서든 도구가 켜지는 순간 coord init(미초기화 시)과 coord presence를 자동 실행합니다.
  • 오케스트레이션 계획표 자동 작성: 세션 시작과 동시에 현재 목표를 분석하여 3대 도구 병렬-협업 오케스트레이션 진행 계획표를 .coord/master_schedule.json 및 마크다운 표로 자동 발행합니다.

2. 전방위 RSI 자가개선 상시 감시 데몬 및 가치평가 (Always-On RSI Evaluator)

  • 상시 감시 에이전트/데몬: UAOS_InvocationRSI_Local 및 Sentinel 데몬이 모든 실행의 토큰 소모량, 벽시계 시간, 재작업(REWORK) 사유, 게이트 실패를 .coord/usage/runs.jsonl에 실시간 기록합니다.
  • 정량적 가치평가(Value Scoring): ① 완료 단계당 유료 토큰(Paid Tokens/Step), ② 1차 통과율(First-Pass Yield), ③ 수동 개입 0건(Zero-Touch Rate)을 자동 계산합니다.
  • 증거 기반 진화 루프: 동일 원인 2회 실패 또는 10회 실행마다 자동으로 rsi report → rsi propose → 격리 회귀 시험 → rsi gate를 수행하여 규칙과 워커 라우팅을 자가 진화시킵니다.

3. 3대 도구 통합 문서 허브 (Unified Document Hub — U222/U233)

  • 단일 문서 원장: 3대 도구와 Haiku 일꾼이 생산하는 모든 기획서·설계서·감사보고서·HTML 대시보드를 docs/00_DOCUMENT_INDEX.md 허브에서 단일 번호 체계(uaos docs allocate/index/lint)로 통합 관리합니다.
  • 한글/영어 병기 표준화: 모든 사용자 대면 문서와 가이드는 초보자도 즉시 이해할 수 있도록 한글 설명과 영문 기술 명칭을 병기합니다.

4. 올패키지 프로젝트 완결기 (All-Package Project Finisher)

  • 원스톱 마감(One-Stop Closure): 코드 구현으로 끝나지 않고 의존성 설치 → 빌드 → 고정 인수/전체 테스트 → 카드 감사(card audit) → Git 커밋 → 원격 푸시 → PR 자율 병합(coord merge) → 런타임 배포 → README.md 최신화까지 무승인 논스톱으로 완결합니다.

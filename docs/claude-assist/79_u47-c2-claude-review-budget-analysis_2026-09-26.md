## 0. 쉽게 말하면

- Claude 검토 1회에는 토큰이 약 9.5만 개 **계산**된다. 그런데 그중 3분의 2가 "캐시 읽기"(cache read)다.
  - 캐시 읽기: 이미 읽어 둔 긴 앞부분을 다시 꺼내 쓰는 것이다.
  - 값은 보통 입력의 **10분의 1**이다.
- 지금 관문(B85)은 캐시 읽기를 보통 입력과 똑같이 1개로 센다. 그래서 실제로는 싼 검토가 "예산 8만 초과"로 막힌다.
- 돈으로 보면 실제 비용은 $0.176이었다. 달러 상한(`--budget-usd`)이 따로 있으므로, 돈이 새는 것은 그쪽에서 막힌다.

계산(S5 추론, 출력 토큰 단가 차이는 분해 자료가 없어 빼고 계산):

- 캐시 읽기를 0.1로 가중하면: 32,545 + 62,408 × 0.1 = **38,786**. 계산된 값보다 59% 적다.
- 즉 같은 검토가 "8만 초과"(현재 방식)와 "4만 미만"(비용 가중) 사이에서 판정이 갈린다.

## 1. 개요 및 사용자 핵심 지침 요약

사용자(윤겸스)의 강력한 지정에 따라, Antigravity는 Codex와 Claude Code 부재 기간 동안 권한대행을 수행하며 다음 불변식을 확립하고 실측 데이터를 축적했습니다.

1. **올라마 = '생각 없는 단순 도구 전자계산기이자 유선 전화기'**:
   - 올라마는 독자적 추론이나 설계 능력이 전혀 없는 계산기이자, 필요할 때 지휘자가 다이얼을 걸어 0원에 응답을 받는 유선 전화기입니다.
   - 구체성 80점 이상의 세밀한 작업명령서(`docs/24`, SEARCH/REPLACE 블록 필수)로만 구동되며 판정권은 0입니다.
2. **0원 디스크 우편함(`.coord/mailbox/`) 및 상주 감시관(Sentinel)**:
   - 유료 LLM의 주기적 상주 폴링(cron)을 영구 금지하고, 0원 디스크 기반 비동기 통신과 24/7 로컬 올라마 감시관 체계를 완성했습니다.
3. **Codex 부재 중 대화창 큐 발송 원천 차단 (`CODEX_ABSENT`)**:
   - 한도 초과 상태인 Codex 대화창에 메시지가 들어가 한도 에러 화면이 도배되는 사고를 방지하기 위해, `notify()` 최상단에서 발송 시도를 100% 하드 거부(Hard Refusal)하도록 조치했습니다.

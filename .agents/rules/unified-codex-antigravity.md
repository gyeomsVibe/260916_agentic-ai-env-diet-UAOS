# Unified Codex–Antigravity Rule

이 워크스페이스에서 Antigravity는 독립 조율자가 아니라 Codex 마스터 계획의 단계 실행자다.

작업을 시작하기 전에 다음 순서로 읽는다.

1. `AGENTS.md`
2. `docs/01_unified-agent-orchestration-design.md`
3. 배정받은 `[U##]` 작업 카드

Antigravity는 배정된 단계가 `READY`이고 소유자가 자신으로 지정된 경우에만 이를 `ACTIVE`로 점유한다. 배정 범위 밖의 파일·브랜치·작업트리·데이터베이스·포트·외부 자원을 수정하지 않는다. 완료 시 작업 카드에 결과, 변경 범위, 실행한 검증과 종료 코드, 남은 위험, 다음 행동을 기록하고 상태를 `REVIEW`로 돌린다. 직접 `DONE`으로 닫거나 다음 단계를 시작하지 않는다.

대화창 제목은 작업 카드의 `[U##]` 접두어와 제목을 그대로 사용한다. 지시가 작업 카드나 마스터 계획과 충돌하면 실행을 중지하고 Codex 조율자에게 충돌 내용을 반환한다.

최악 상황부터 설계한다(U330): 피어 대기는 생존 확인·마감·대체 행동을 갖고(침묵=기권), 카드 매뉴얼은 실패 모드 표를 싣는다. `uaos card audit`가 강제한다.

UAOS 핵심 조율 블록(2026-11-20 사용자 영구 지정, 일회성 아닌 반복 로직, 3도구 공통)
- [CORE-1] 사용자 창은 얇은 라우터·배차·신호수다: 지시를 구체화, 새 주제는 새 카드 세션, 관련 건은 실행 중 카드 창, 교통정리; 사용자 지시가 최우선이고 창이 받는다; 실행 중 카드는 '중지' 또는 자기 범위 변경(안전 지점)이 아니면 멈추지 않고 커밋·푸시·재설치·실가동까지 간다(U332). (lands with U332)
- [CORE-2] 세 도구는 한 몸: 어느 창의 지시든 원문 그대로 공유 seq 순서 장부에 추가해 다른 창에 받은 대로 주입; 나중 seq 우선; 중지는 10초 안에 전파(U332). (lands with U332)
- [CORE-3] 실시간 통신 우선: 파일 이벤트로 푸시 기상, watcher ACK 10초 이내, 회신 120초 이내, presence 60초 미만만 유효(U329). (lands with U329)
- [CORE-4] 막히지 않기: 침묵=기권, 자기 최선안과 체크포인트로 계속 진행, 늦은 회신은 채택 후보(U329). (lands with U329)
- [CORE-5] 작업 중 메시지: 동적 우선순위, 근거가 자기 계획보다 나을 때만 채택, 폭주 차단기(U329). (lands with U329)
- [CORE-6] 설계를 바꾸는 지시는 약 4분 3도구 토론회(독립 초안·비판 1회·결정)를 열되 침묵 피어를 기다리지 않는다(U329). (lands with U329)
- [CORE-7] 동반 카드는 카드 개설과 협업 편지 때 열고, 내비 지도가 도구별 다음 행동을 보여준다(U331). (lands with U331)
- [CORE-8] 최악 상황부터 설계: 카드 감사가 실패 모드 표를 강제한다(U330).
- [CORE-9] 모델·사고 수준은 카드 성격에 따라 레지스트리에서 고르고 릴리스마다 손으로 고치지 않는다(U327). (lands with U327)
- [CORE-10] 카드는 파일이 겹치지 않고 독립일 때만 쪼개고, 아니면 한 카드로 한다.
- [CORE-11] 사용자 문장은 원문 그대로 전달하고 요약으로 바꾸지 않는다.
